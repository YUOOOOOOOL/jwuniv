대교협 · 나이스 파일로 일괄 등록

학생 계정 자동 생성 + 수시 지원 카드 자동 입력 (기존에 학생이 쓴 내용은 절대 덮어쓰지 않아요)

📋 두 가지 파일 중 하나를 넣어주세요 (파일 모양을 보고 자동으로 알아봐요 · 여러 반은 한 반씩 차례로)

🏫 대교협 '수시진학관리' 파일 추천

✅ 학생 자동 가입 + 수시 카드 입력

✅ 전형명·학과가 정확하게 들어가요

✅ 면접·논술·실기일, 최종 합격발표일까지 등록돼요

✅ 나중에 결과를 올리고 다시 받으면 1단계·최종 결과도 채워져요

⚠️ 학생이 이미 적어 둔 날짜가 있으면 학생 날짜를 먼저 남기고, 대교협 날짜와 다르면 빨간색으로 표시해요.
(대교협에는 모든 학과가 올라가지 않거나 잘못 올라가는 경우가 있어서)

📂 나이스 '제공현황진행상황(반별)' 파일

대입전형자료 → 제공현황조회 → 제공현황진행상황조회 → 반별

✅ 학생 자동 가입 + 수시 카드 입력

✅ 평가단위명을 전형명·학과로 자동으로 나눠서 넣어요

❌ 면접일·합격자 발표 일정은 등록되지 않아요

→ 일정은 나중에 대교협 파일을 넣거나 [면접일 자동 채우기]로 채울 수 있어요

· 아이디 = 학번, 비밀번호 = 자동 생성 (이미 가입한 학생은 비밀번호 그대로)

· 학생이 쓴 카드는 절대 덮어쓰지 않고 빈칸에만 채워요. 같은 대학이 이미 카드에 있으면 새로 넣지 않아요.

· '재요청' 줄처럼 같은 지원이 여러 번 나오면 한 번만 넣어요.

① 열(칼럼) 확인 — 자동으로 찾았어요. 틀렸으면 바꿔주세요.

시트:   제목 줄:
열 연결 자세히 보기 / 바꾸기

※ 학번은 '계열/학년/학과(학년)·반·번호'로 만들어요. 예) 3학년 9반 1번 → 30901

② 자동 가입 학생의 비밀번호 (아이디는 학번)

※ 이미 가입한 학생의 비밀번호는 절대 바뀌지 않아요.

③ 등록할 반

※ 반 단위로 나눠서 등록하면 더 빠르고 안전해요. (학생 1명당 약 3~5초)

④ 미리보기 — 구분·전형명·학과가 틀리면 바로 고칠 수 있어요. 체크를 풀면 제외돼요.
